Mon projet de création d'un site web interactif "Mini jeu"

Site web interactif pour le thème "EAU"

Mon projet est réalisé dans le cadre du cours "sémiotique d'interface" assuré par : Mr. Everardo REYES. Ce projet est considéré comme un site interactif qui est basé sur un jeu qui traite le thème de l'eau". J'ai utilisé de différents langages pour pouvoir rendre le jeu interactif.

Site web interactif sur l'eau à l'université Paris 8 (2025/2026)

Ce projet est un site multi-pages proposant un jeu et une navigation intuitive.

  • Page d’accueil : un background animé, 4 block de jeux cliquables: Fôret, animaux, cycle de l'eau, mer
  • Page Fôret : jeu cliquable avec une mini narration pour sauver la nature grâce à la pluie
  • Page animaux : Nourrir les animaux (nourriture et eau) pour leur donner la vie.
  • Page cycle de l'eau : glisser les éléments qui forment le cycle de l'eau selon les étapes
  • Page mer: Sauver les animaux de la mer

Ce site combine HTML, CSS, JavaScript et outils comme illustrator pour offrir une expérience interactive et pédagogique.
