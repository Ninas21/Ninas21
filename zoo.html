Site web dynamique – Projet de formation CNAM (2020/2021)

Ce projet, réalisé dans le cadre de ma formation au CNAM, est un site dynamique pour un zoo fictif. Il intègre :

  • Un système d’inscription et de connexion des visiteurs
  • Une gestion de contenu dynamique (affichage des animaux, informations…)
  • Un design responsive réalisé en HTML et CSS
  • Une base de données reliée via PHP et WampServer

Les images utilisées proviennent de sources libres ou trouvées sur Internet et ne sont pas de ma création. Il s’agit de mon premier site web complet, et donc de ma première mise en pratique concrète après avoir appris :

  • Les bases du HTML/CSS
  • La gestion de bases de données
  • La configuration d’un serveur local (WampServer)
  • Les bases de PHP

Ce projet m’a permis de comprendre la logique d’un site dynamique, de manipuler les interactions avec une base de données et de mettre en place un parcours utilisateur simple mais fonctionnel.
