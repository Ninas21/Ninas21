Mon projet de création d'un site web interactif

Site web interactif en datavisualisation

Mon projet est réalisé dans le cadre du cours "Introduction aux outils numériques" assuré par : Mr. Everardo REYES. Ce projet est considéré comme un site interactif qui est basé sur des données d'un artiste connu dans le monde entier "Michael Jackson". J'ai utilisé de différentes technologies et sites en ligne qui ont facilité l'accès aux données variées.

Site web interactif sur la carrière de Michael Jackson à l'université Paris 8 (2024/2025)

Ce projet est un site multi-pages proposant navigation intuitive via une bannière (“Accueil, Histoire, Chansons, Jeu, Download, Projet”).

  • Page d’accueil : bannière, image de Michael Jackson avec TagCloud animé (non cliquable), accès rapide aux sections Histoire et Chansons.
  • Page Histoire : brève biographie, style musical, graphiques interactifs créés via des outils comme Observable et Canva.
  • Page Chansons : TagCloud animé + TagCloud cliquable (HTML/CSS) menant à une page dédiée par chanson, avec paroles, analyses textuelles (Voyant Tools), graphiques interactifs et effet visuel “mots qui tombent”.
  • Page Jeu : deux mini-jeux en JavaScript.
  • Page Download : fichiers téléchargeables (.csv, .json).
  • Page Projet : présentation complète du projet de A à Z.

Ce site combine HTML, CSS, JavaScript et outils externes pour offrir une expérience interactive et pédagogique.
